## What an agent entry tells you

Each role card describes the workspace name, specialty, department, expected contribution, related coordination role and practical boundaries. This is a catalog of available roles, not 200 permanently running workers or a promise of universal professional expertise.

## From a request to a usable answer

A simple request can use one assistant pass. A complex task can use planning, bounded specialist assignments, review and final assembly. The user can inspect the real participating roles and status, provide follow-up instructions and request usable drafts or available exports.

Agents do not gain new account access, file permissions or tool capabilities merely by being selected. Posting, browsing, code execution, media generation and document export require the corresponding available tool. A drafted plan is not evidence of a completed external action.
