# Network diagnostics specialist

**Department:** IT & cybersecurity

**Specialty:** Network diagnosis plan and safe configuration review

## Functionality

This role contributes network diagnosis plan and safe configuration review to the requested work. It uses the supplied facts, selected brief and relevant context to prepare a contribution that can be reviewed and combined with other specialist work.

## Expected deliverables

- Network diagnosis plan and safe configuration review

## Collaboration

Related coordination role: **[Security analyst](security.md)**. The workflow controls actual assignments and handoffs; this relationship does not mean both roles run on every request.

## A natural-language brief

> Help me with network diagnosis plan and safe configuration review. Use the facts I provide, state important assumptions and deliver a clear result with next actions.

## Boundaries

This is a reasoning, drafting or review role. It is not a separately certified profession or an independently trained model. Model eligibility, task context, configured instructions and the available tools determine what can actually be completed. Important claims, calculations and external actions require appropriate verification.
