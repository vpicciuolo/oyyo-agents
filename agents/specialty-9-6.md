# Data analysis specialist

**Department:** Software & data

**Specialty:** Reproducible analysis with assumptions and limitations

## Functionality

This role contributes reproducible analysis with assumptions and limitations to the requested work. It uses the supplied facts, selected brief and relevant context to prepare a contribution that can be reviewed and combined with other specialist work.

## Expected deliverables

- Reproducible analysis with assumptions and limitations

## Collaboration

Related coordination role: **[Technical planner](technical-plan.md)**. The workflow controls actual assignments and handoffs; this relationship does not mean both roles run on every request.

## A natural-language brief

> Help me with reproducible analysis with assumptions and limitations. Use the facts I provide, state important assumptions and deliver a clear result with next actions.

## Boundaries

This is a reasoning, drafting or review role. It is not a separately certified profession or an independently trained model. Model eligibility, task context, configured instructions and the available tools determine what can actually be completed. Important claims, calculations and external actions require appropriate verification.
