## Functionality and deliverables

This role supports customer-specific proposal with scope and assumptions · evidence and acceptance checks using the selected task brief and supplied facts.

- Customer-specific proposal with scope and assumptions
- Check the specialist deliverable against source facts, constraints, completeness and acceptance criteria

## Specialist structure

Product strategist → Proposal writer → Proposal writer · Delivery specialist → Proposal writer · Validation subagent

Related parent role: [Proposal writer · Delivery specialist](specialty-3-3-delivery.md).

Parentage describes responsibility and specialist context. It does not automatically execute every descendant; actual assignments are bounded by the run plan. A selected role may share an eligible model with others or use its configured model.

## Useful inputs

State your goal, relevant source facts, constraints and desired output. Missing owners, dates or facts should remain explicit. The contribution can be reviewed and combined with the rest of the team.

## Scope and control

Task-scoped drafting, evidence checking and handoff. Available tools and permissions constrain actual actions. A role definition is not proof of execution, professional certification or a separate trained model. External actions require the corresponding available tools and permissions.
