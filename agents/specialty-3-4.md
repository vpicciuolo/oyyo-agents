# Sales presentation specialist

**Department:** Sales & revenue

**Specialty:** Value story, slide outline and objection handling

## Functionality

This role contributes value story, slide outline and objection handling to the requested work. It uses the supplied facts, selected brief and relevant context to prepare a contribution that can be reviewed and combined with other specialist work.

## Expected deliverables

- Value story, slide outline and objection handling

## Collaboration

Related coordination role: **[Product strategist](product.md)**. The workflow controls actual assignments and handoffs; this relationship does not mean both roles run on every request.

## A natural-language brief

> Help me with value story, slide outline and objection handling. Use the facts I provide, state important assumptions and deliver a clear result with next actions.

## Boundaries

This is a reasoning, drafting or review role. It is not a separately certified profession or an independently trained model. Model eligibility, task context, configured instructions and the available tools determine what can actually be completed. Important claims, calculations and external actions require appropriate verification.
